# مختبر الكشف الذكي — نور مهند احمد

كورس جامعي بالعربية مع المصطلحات الإنكليزية، من 10 محاضرات حول كشف برمجيات الفدية باستخدام 1D-CNN وDistilBERT.

المصدر الأساسي: [الورقة المنشورة على IEEE Xplore](https://ieeexplore.ieee.org/document/11659649).

## التشغيل

افتح `index.html` في المتصفح مباشرة. جميع ملفات الواجهة محلية ولا تحتاج تنزيل مكتبات أو إنشاء حساب. البحث والتنقل يعملان دون خادم. حفظ التقدم يعتمد على دعم المتصفح للتخزين المحلي.

للمعاينة عبر خادم محلي اختياري:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

## تعديل المحتوى

عدّل `course.md` ثم شغّل:

```sh
python3 build.py
```

الملفات:

- `index.html`: واجهة الكورس وبطاقة المصدر.
- `style.css`: التصميم العربي المتجاوب والطباعة.
- `app.js`: التنقل والبحث وحفظ الإنجاز في المتصفح.
- `content.js`: المحتوى المبني، لا تعدّله يدوياً.
- `favicon.svg`: أيقونة الكورس.
- `course.md`: مصدر المادة التعليمية القابل للتعديل.
- `build.py`: توليد المحتوى باستخدام Python دون مكتبات إضافية.

## الوصول الخاص

أنشئ المستودع بحالة **Private** واحتفظ بها. أضف من تريد عبر Settings → Collaborators → Add people. لا يوجد مشاركون مضافون تلقائياً ضمن ملفات هذا المشروع.

هذه حزمة ثابتة قابلة للتنزيل من المستودع وليست بوابة تسجيل دخول. خصوصية المستودع لا تُنشئ حماية وصول لأي موقع منشور منه؛ لا تفعّل نشراً عاماً. إذا احتجت رابط موقع محمياً للطلاب، يجب إعداد استضافة تدعم تسجيل الدخول وقائمة مستخدمين مسموح بها والتحقق منها قبل النشر.

الوسم `noindex` ليس آلية حماية. من تسمح له بتنزيل الملفات يمكنه الاحتفاظ بنسخة؛ إزالة وصوله من GitHub تمنع الوصول اللاحق إلى المستودع ولا تمحو نسخه السابقة.
